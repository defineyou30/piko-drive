3. 패키징 (APK 이름 정리 + 접수양식에 GitHub 링크 반영):
   ```bash
   TEAM=팀명 GITHUB_URL=https://github.com/<계정>/piko-drive tools/package_submission.sh
   ```
   "기획서 링크 반영 완료"가 나와야 함.
4. 커밋 후 공개용 폴더 만들기·올리기:
   ```bash
   git add -A && git commit -m "제출 패키지"
   tools/make_public_repo.sh ../piko-drive-public
   cd ../piko-drive-public && git remote add origin https://github.com/<계정>/piko-drive.git && git push -u origin main
   ```
