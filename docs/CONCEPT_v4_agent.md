# 컨셉 v4 — 피코: 아이 일정·안전 에이전트 (2026-10-26)

v3(뒷자리 아이 루틴 + 앞자리 자동 체크, `CONCEPT_v3_kids_ride.md`)를 기반으로 방향을 넓힌다.
사용자 피드백: "캐릭터가 하찮다", "운전석 화면과 아이 화면을 나눌 수 없나", "아이 스케줄·안전을 관리하는 에이전트 느낌, 스케줄·메모도 저장".

## 1. 한 줄
**피코는 부모에게는 아이 일정·안전 비서, 아이에게는 뒷좌석 친구.**

## 2. 두 화면
| 화면 | 누구 | 내용 |
|---|---|---|
| 운전석 (앞) | 부모 = 운전자 | 에이전트 브리핑: 다음 일정, 오늘 일정, 상황 메모, 뒷좌석 자동 체크, 오늘 안전 기록. 주행 중엔 텍스트 0·음성만 (v2 정책 유지) |
| 뒷좌석 | 아이 | 큰 피코 얼굴, 말풍선, 스티커판. 운전자 화면이 아니라 주행 중에도 움직인다 |

- 뒷좌석 화면 찾기: 실차는 AAOS `CarOccupantZoneManager`의 뒷좌석 탑승자 구역 메인 디스플레이, 없으면 보조 디스플레이, 그것도 없으면 **음성만** (`RearDisplay`).
- 실측: 에뮬레이터에 보조 디스플레이(`adb emu multidisplay add`)를 붙여 `RearActivity`가 그 화면에 뜨는 것을 확인 (`qa/v4/rear/`).
- **한계:** 실제 Pleos 차량에 뒷좌석 화면이 있는지는 확인 전. 이 에뮬레이터 이미지는 보조 디스플레이를 붙이면 몇 분 안에 시스템 앱(IME·차량 제어·SystemUI·car service)이 연달아 죽는다 → 두 화면 시연은 짧게, 전체 E2E는 앞 화면만.

## 3. 에이전트 기능
| 기능 | 동작 | 근거 신호 |
|---|---|---|
| 일정 | 아이별 요일·시각·제목·준비물. 시각 10/15/30분 전에 운전자에게 음성 브리핑, 앞 화면에 다음 일정 카드 | 벽시계 |
| 상황 메모 | "언제 꺼낼지"를 정해 둔다: 아이가 탈 때 / 출발할 때 / 도착하면 / 아이가 내릴 때 / 정한 시각. 한 번 또는 매번, 아이 지정 가능 | 뒷좌석 착석 전이, 정차↔주행 전이, 벽시계 |
| 안전 기록 | 보조 알림이 실제로 울린 일을 하루 단위로 기록 (미체결 출발, 주행 중 벨트 풀림, 주행 중 문 열림, 차도 쪽 문, 뒷좌석 남김). 7일 보관 | v3 루틴 이벤트 |
| v3 그대로 | 뒷좌석 자동 체크, 남김 보조 알림, 쉿 모드(조명), 보호자 알림 웹훅, 스티커 | v3 |

예) 메모 "콩이 쪽 문 닫혔는지 확인" (아이가 내릴 때 · 매번 · 콩이) → 콩이 착석이 풀리는 순간 "메모예요. 콩이 쪽 문 닫혔는지 확인".

## 4. 캐릭터: 바이저 (시안 B, `design/v4/agent_drafts.png`)
- 매끈한 흰 캡슐 몸 + 어두운 바이저 + 그 안의 빛 점 눈. 현대차 전기차의 픽셀 램프와 같은 조명 언어 → "Pleos용" 캐릭터.
- 표정 = 빛 점 패턴 (평온 2x3 블록, 기쁨 ^, 놀람 ○, 졸림 —, 조용 ·).
- 이마의 빛 점 10개 = 스티커판. 해금: 1판 볼 램프, 2판 귀 램프.
- 앞 화면에서는 작은 에이전트 아이콘, 뒷좌석에서는 큰 얼굴.
