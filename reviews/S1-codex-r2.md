이전 Top 5 판정:

1. **캐릭터 문법 통일 — 부분**
   - 3×3 눈 규칙은 코드와 FRAMEWORK에 통일됨.
   - 다만 눈 주변 1칸 여백은 코드로 보장되지 않아 FACE 이상에서 몸 픽셀과 표정이 여전히 붙음.

2. **성장 단계 식별성 재설계 — 부분**
   - 더듬이·발·앰버 팁 등 단계별 표식이 추가되어 시트 구분은 개선됨.
   - 실제 화면에서 1초 이내 식별되는지에 대한 검증 증거는 없음.

3. **주행 중 표정·모션 제한 — 부분**
   - 후진 정지, 성장 동결, 10초 표정 쿨다운 로직은 추가됨.
   - F4/F5 이벤트 조건과 TTS 정책은 엔진이 아니라 화면 목업 수준이며, 300ms 전환도 명시적으로 애니메이션 검증되지 않음.

4. **차량 화면 정보 계층·대비 — 부분**
   - 캡션이 18sp로 개선되고 F6의 놀란 순간 기준도 표시됨.
   - F1/F6 정보량은 여전히 많고, Pleos 실제 해상도·주야간 조건 검증은 없음.

5. **F0·F1·F6 카피와 행동 계약 — 부분**
   - F0 약속 문구와 F6 통계 의미는 명확해짐.
   - 버튼들이 실제 다음 상태로 연결되지 않고, F2/F5가 F3 화면을 재사용함.

새로 생긴 문제:

- F8 설정 선택값이 로컬 UI 상태에만 머물러 재진입·앱 재시작 시 유지되지 않음.
- F0/F1/F6 버튼에 기본 no-op 핸들러가 있어 화면상 동작처럼 보이지만 실제 전환·피드백이 없음.
- 실제 차량 HMI와 무관한 임시 에뮬레이터 캡처만 있어 안전성·가독성 증거로 사용할 수 없음.
