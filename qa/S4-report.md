| 항목 | 내용 |
|---|---|
| 상태 기반 화면 | `LiveScreen`: BOOTING·DRIVING→F3, REVERSING→F3R, PARKED→F0(첫 실행)/F6(새 리포트)/F1(+리포트·설정·데모). 출발 시 하위 화면 자동 닫힘 |
| F2 전환 | 화면 키 단위 Crossfade **300ms** (`MotionBudget.DRIVING_TRANSITION_MS`) |
| F0 첫 만남 | 2단계 (인사 → 운전 안전 약속), 완료 플래그 저장 |
| F1 | 실제 펫 상태·성장 진행 바·**오늘 요약(실제 리포트 기반)**·쓰다듬기(엔진 petByHand) |
| F6 | 실제 트립 리포트: 시간대, 편안한 시간, 놀란 순간, 늘어난 픽셀, 타임라인. F1 "리포트"로 재열람 |
| F8 | **실제 동작 항목만**: 피코 목소리 켜기/끄기(엔진 voiceEnabled, 끄면 QUIET 표정), 밤에는 은은하게(자동 19~6시/항상/끄기, 휘도 60%). S1 목업의 "말하기 빈도"는 엔진에 연결되지 않아 제거 |
| F9 | 숨은 진입(단계 라벨 5탭). 성장 가속(데모 판정 기준 포함, 세션 재시작), 목소리 테스트, 피코 초기화, 데이터 출처(Pleos/SIM) 표시 |
| 저장 | DataStore: 펫 상태·최근 리포트 30개(벽시계로 저장)·설정. 서버 없음 |

| 지적 | 조치 |
|---|---|
| F9에 "Pleos" 브랜드명 노출 | "실차량"으로 변경 (FRAMEWORK 1-2 상표 원칙) |

| **주행 화면이 거의 빈 화면 → 차량 특화성 약함** | ① 미점등 실루엣을 주행 중에도 정적으로 표시("자라날 자리") ② 하단 **주행 픽셀 바**: 편안한 주행이 다음 성장까지의 칸을 채움 (5~10초 주기 갱신, 텍스트 0, 후진 중 숨김) → "운전이 곧 성장"을 주행 중에 보여줌 |
