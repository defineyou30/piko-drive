## 2. 뒷좌석 화면 (`rear/`)
`adb emu multidisplay add 1 1280 800 160 0` 후 앱 실행 → `RearDisplay`가 보조 디스플레이(id 2)를 찾아 `RearActivity`를 띄움.
캡처는 `adb emu screenrecord screenshot --display 1` (screencap은 가상 디스플레이를 못 찍음).
- 02 탑승 말풍선, 03 스스로 벨트 → 이마 빛 점 2칸·말풍선, 05 주행 중에도 표시.
- 04 쉿 모드 화면은 캡처 실패: 두 화면일 때 ui.py(uiautomator)가 앞 화면 버튼을 못 눌렀다. 쉿 모드 동작 자체는 1번 E2E에서 확인.

## 3. 발견·수정
- **보조 디스플레이를 붙이면 에뮬레이터 시스템이 불안정**: 수 분 안에 IME → 차량 제어 → SystemUI → car service → VHAL이 연달아 죽고, 부하 평균 100 이상에서 우리 앱도 입력 포커스 ANR로 종료. 이후 시스템이 서비스를 백그라운드에서 되살리며 포그라운드 시작이 거부돼 **우리 앱이 반복 크래시** → `PikoDriveService`가 거부되면 조용히 멈추도록 수정.
- 캐릭터 호흡을 60fps 연속 → 6단계 계단식으로 (두 화면 동시 표시 부하).
- 데모 일정이 자정을 넘기면 '지난 일정'으로 보이던 것.
